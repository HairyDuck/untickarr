Tags & Blacklist

Only torrents with these tags are processed. Files with blacklisted extensions are unticked; if all files are blacklisted, the torrent is removed.

Use the exact tag names shown in your download client. Substring match: "sonarr" also matches "tv-sonarr".

Files with these extensions are unticked. Pick by category or add your own.
